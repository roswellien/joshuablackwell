# Joshua Blackwell — portfolio explorations

Two buildless, responsive portfolio concepts on GitHub Pages:

- `/`: comparison and navigation
- `/curved/`: navy curved switchboard with directional arrow and section transitions
- `/photo/`: green/rust expanding panels and personal photography

Both include keyboard navigation and reduced-motion support. Shared image assets are in `assets/`. Photograph metadata is removed except the orientation required for correct rendering. No analytics, forms, external fonts, or build dependencies are used.

Run `python -m http.server 8768 --bind 127.0.0.1` in this directory to preview.

GitHub Pages publishes the root of `main`; the existing custom domain is `joshuablackwell.me`.
